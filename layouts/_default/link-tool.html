How this works — read once

What UTM tags are for. They tell GA4 where a visitor came from. You add them to a link and publish that link outside the site — in a post, an ad, an email, a Telegram channel.

Rule #0 — tag external links only. Never tag a link that both lives on our site and points to the same site (menus, internal banners). A UTM on an internal link resets the real source in GA4 and you lose the true origin.

  • Platform / resource = where the link physically sits (LinkedIn, a Telegram channel, Google Ads…). Each Telegram channel is its own source.
  • Placement type = how the traffic is earned. Organic post → social; paid ad → paid_social; search ad → cpc; email → email. These exact values let GA4 sort traffic into the right channel.
  • Campaign = the initiative, one name everywhere. Pick a launch date from the calendar and it’s appended automatically.
  • Content / Term = optional: creative variant (A/B, which post/button) and paid-search keyword.

Cross-site banners. Banner on cozystack.io pointing to aenix.io (or the reverse) → set Platform to the site the banner sits on. Same-site → don’t tag (the tool warns you).

Then: Copy URL for any site, or Shorten for aenix.io links (needs the team secret; only aenix.io / k.aenix.io / opc.aenix.io can be shortened — anti-fraud). The short link is aenix.io/l/<slug> and its clicks show up in GA4.
