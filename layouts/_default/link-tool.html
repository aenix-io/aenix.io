How this works — read once

What UTM tags are for. They tell GA4 where a visitor came from. Add them to a link and publish it outside the site — a post, an ad, an email, a Telegram channel.

Rule #0 — tag external links only. Never tag a link that lives on our site and points to the same site (menus, internal banners). A UTM on an internal link resets the real source in GA4 and you lose the true origin. The tool warns you when it detects this.

  • Platform / resource (utm_source) = where the link sits — a network, a community, an event. Each Telegram channel is its own source.
  • Channel (utm_medium) = the GA4 traffic type. Only GA4-valid values are offered (social, paid_social, cpc, display, video, email, referral, affiliate) so nothing falls into “Unassigned”. Format/creative does NOT go here — it goes in Content.
  • Campaign = one stable name for the whole initiative. Region / funnel / type are folded in as a prefix so you can filter (e.g. emea_tofu_event_cloudfest2026). No dates in the campaign — the launch date goes to utm_id instead, keeping reports rolled-up.
  • Content (utm_content) = the creative/variant for A/B and placements (banner-a, story-swipeup). Term = paid-search keyword only (appears when Channel = cpc).

⚠ Paid search (Google/Bing Ads). Those platforms auto-tag with GCLID/MSCLKID. Do NOT hand-tag paid-search final URLs — it breaks the Ads↔GA4 cost/attribution join. Use auto-tagging + GA4 linking. The tool warns on google/bing + cpc.

Two sites. aenix.io and cozystack.io have separate GA4 properties. A short aenix.io/l/… link that targets cozystack.io redirects (302) and preserves the UTMs — the landing is attributed in cozystack’s property; the click count lives in this tool’s registry. For cross-site banners set Platform to the site the banner sits on.

Shortening. Copy URL works for any site; Shorten is for aenix.io links only (anti-fraud allow-list). Short links are aenix.io/l/<slug>, redirect server-side with a first-party click counter (works even with ad-blockers), and every link you build is logged to the registry.
