Wir freuen uns, das Webinar von Andrei Kvapil für die CNCF vorzustellen! Er zeigt ausführlich, wie sich aus Open-Source-Komponenten eine leistungsfähige Cloud-Plattform aufbauen lässt.

Darin erfahren Sie:

- welche Architekturansätze es gibt und wie man die API gestaltet,
- wie Sie die passenden Komponenten auswählen,
- mit welchen Strategien Sie diese zu einer robusten Infrastrukturlösung zusammenführen.

Besonders sehenswert ist das Webinar für:

- Unternehmen, die aus der Public Cloud auf eigene oder gemietete Server umziehen wollen,
- Hosting- und Service-Provider, die mit Hyperscalern wie AWS konkurrieren möchten.

Jetzt ansehen!
