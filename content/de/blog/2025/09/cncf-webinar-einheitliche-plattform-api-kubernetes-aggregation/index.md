![CNCF-Webinar: One API to Rule Them All](/img/blog/medium/cncf-webinar-one-api-to-rule-them-all-building-a-unified-platform-with-kubernetes-aggregation/cover.jpg)

Wie wird aus einem Stapel Open-Source-Werkzeuge ein einheitliches Produkt? In diesem Vortrag zeichnet ein Core-Maintainer von Cozystack den technischen Weg nach: wie Helm, Operatoren und der Kubernetes Aggregation Layer zusammengeführt wurden, um eine universelle API aufzubauen – ganz ohne etcd.

Erfahren Sie, wie ein dynamischer API-Server, eine universelle GUI für Operatoren und ein Echtzeit-Abrechnungssystem auf Basis von Prometheus entstanden sind. Ein tiefer Einblick in Platform Engineering und in die praktischen Herausforderungen beim Bau von Open-Source-Cloud-Plattformen.
