## Branchen im Überblick

### Hochreguliert

- **[Finanzdienstleistungen](/de/branchen/finanzdienstleistungen/)** — Banken, Versicherer und Marktinfrastruktur im Anwendungsbereich von DORA. Passende Plattform: Private Cloud Platform.
- **[Versicherung](/de/branchen/versicherung/)** — DORA, sektorale Datengesetze und KI in der Schadenbearbeitung. Passende Plattformen: Private Cloud Platform + AI Platform.
- **[Öffentlicher Sektor](/de/branchen/oeffentlicher-sektor/)** — Behörden-Cloud, ausgerichtet an nationalen Souveränitätsvorgaben. Passende Plattform: Private Cloud Platform oder Public Cloud Platform.
- **[Gesundheitswesen](/de/branchen/gesundheitswesen/)** — Sektorale Datengesetze (nationale Entsprechungen zu HIPAA), KI auf regulierten medizinischen Daten. Passende Plattformen: Private Cloud Platform + AI Platform.
- **[Energie](/de/branchen/energie/)** — Wesentliche Einrichtung nach NIS2, Edge-Cloud, KI-gestützte Optimierung. Passende Plattform: Private Cloud Platform.
- **[Transport / Logistik](/de/branchen/transport-logistik/)** — Wesentliche Einrichtung nach NIS2, multimodale Logistikinfrastruktur. Passende Plattform: Private Cloud Platform.

### Cloud / Hosting / MSP

- **[Hosting-Anbieter](/de/branchen/hosting-anbieter/)** — Regionale Hosting-Anbieter, die Cloud-Produkte aufbauen. Passende Plattform: Public Cloud Platform. Öffentlich genannte Produktivkunden: GoHost.kz, HDReady, Beby Cloud, HiKube, UseTech, Cloupard, Cloudsy.
- **[MSP](/de/branchen/msp/)** — Managed Service Provider, die Enterprise-Kunden eine Cloud unter eigener Marke anbieten. Passende Plattform: Public Cloud Platform (White-Label).
- **[Telco](/de/branchen/telco/)** — Telekommunikationsbetreiber: wesentliche Einrichtung nach NIS2 und Cloud-Produkt für Kunden. Passende Plattform: Public Cloud Platform oder Private Cloud Platform.

### Industrie / Bildung

- **[Fertigung](/de/branchen/fertigung/)** — Edge- und IT/OT-Cloud-Plattform für Industriebetriebe. Passende Plattform: Private Cloud Platform.
- **[Universitäten](/de/branchen/universitaeten/)** — Research Computing, souveräne Studierendendaten und KI/ML-Labore. Passende Plattformen: Private Cloud Platform + AI Platform.
- **[Schulbildung (K-12)](/de/branchen/k12-bildung/)** — Souveräne Cloud für Schulträger und Bildungsministerien. Passende Plattform: Private Cloud Platform.

### KMU / Mittelstand

- **[KMU / Mittelstand](/de/branchen/mittelstand/)** — Kleinere Organisationen, die Cloud als Produkt beziehen. Passende Plattform: Public Cloud Platform über einen Service-Provider-Partner oder [Cozystack mit Enterprise-Support von Ænix](/de/produkte/cozystack-enterprise-support/).

## Referenzen

**Hosting-Anbieter, die die Ænix Public Cloud Platform produktiv betreiben:** GoHost.kz, HDReady, Beby Cloud, HiKube, UseTech, Cloupard, Cloudsy.

**Projekte unter NDA** (Banken, souveräne Cloud, AI/ML, Telco): Die Kundennamen sind vertraglich geschützt. [Neun Deployments sind ausführlich beschrieben](/de/case-studies/), anonymisiert, aber mit vollständiger Architektur und allen Zahlen — darunter [eine Private Cloud in einer Bank](/de/case-studies/private-cloud-in-a-bank/) und [ein einheitliches Cloud-Portal für eine Finanzgruppe](/de/case-studies/unified-cloud-portal-financial-group/).

**Plattform-F&E für Anbieter im Ökosystem:** Entwicklung von CSI-Treibern, Forschung zu Virtualisierungsplattformen, Public-Cloud- und VPS-Hosting-Plattformen, schlanke VDI, Backup-Systeme, die die Speicherkosten um bis zu 75 % senken. [Fallstudien ansehen →](/de/case-studies/)

## Branchendaten, die wir zitieren

- **Broadcom Private Cloud Outlook 2025:** 53 % priorisieren Private Cloud für neue Workloads; 69 % erwägen eine Rückverlagerung von Hyperscalern
- **LSEG Global Cloud Survey 2025 (Finanzdienstleistungen):** 84 % haben ihre Cloud-Strategie wegen regulatorischer Vorgaben angepasst
- **Nutanix Financial Services ECI 2025:** 92 % halten ihre Infrastruktur nicht für Cloud-native bereit; 62 % stellen GenAI-Spezialisten ein

Es handelt sich um Umfragen aus dem Jahr 2025, zwei davon von Infrastrukturanbietern (Broadcom, Nutanix) veröffentlicht; lesen Sie sie als Richtungsangabe, nicht als unabhängige Messung.
