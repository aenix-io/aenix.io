**Ænix baut und betreibt Cloud-Plattformen auf Hardware, die Sie kontrollieren — für Organisationen, die echte Cloud-Infrastruktur brauchen, aber keinen Hyperscaler darunter. Die meisten kommen aus einem von wenigen Gründen hierher: eine Aufsichtsbehörde (DORA, NIS2), eine Souveränitätsanforderung, ein KI-Workload, der das Haus nicht verlassen darf, eine Cloud-Rechnung, die nicht mehr aufgeht, eine anstehende VMware-Verlängerung, eine Pflicht zur Betriebskontinuität oder Entwickler, die wochenlang auf eine Umgebung warten. Wählen Sie den passenden Grund — die jeweilige Seite beschreibt die Architektur, die passende Ænix-Plattform und den Ablauf eines Projekts.**

## Lösungen nach Auslöser

### Regulatorische Auslöser

- **[DORA-Compliance](/de/loesungen/dora-compliance/)** — Cloud-Architektur, abgebildet auf das IKT-Risikomanagement der DORA (Art. 5–16), die Behandlung und Meldung von IKT-Vorfällen (Art. 17–23, schwerwiegende Vorfälle nach Art. 19), das IKT-Drittparteienrisiko (Art. 28–30, Konzentrationsrisiko in Art. 29) sowie die Resilienztests (Art. 24–27). Passt zu: Private Cloud Platform. Kostenlose [DORA-Checkliste](/de/ressourcen/dora-compliance-checkliste/).
- **[NIS2-Compliance](/de/loesungen/nis2-compliance/)** — Risikomanagement-Maßnahmen (Art. 21) und Meldepflichten mit 24-Stunden-, 72-Stunden- und Ein-Monats-Frist (Art. 23) für wesentliche und wichtige Einrichtungen. Passt zu: Private Cloud Platform. Kostenlose [NIS2-Checkliste](/de/ressourcen/nis2-compliance-checkliste/).
- **[Datensouveränität](/de/loesungen/data-sovereignty/)** — Hardware unter Ihrer Kontrolle, dokumentierte Schlüsselverwahrung und Datenresidenz für jede Datenklasse. Passt zu: Private Cloud Platform oder Public Cloud Platform.
- **[Disaster Recovery](/de/loesungen/disaster-recovery/)** — Synchrone Replikation über Rechenzentren hinweg, Backups außerhalb des geschützten Clusters, RTO und RPO, die Sie in einer Notfallübung belegen können. Passt zu: Private Cloud Platform.

### Auslöser aus KI und GPU

- **[Souveräne KI](/de/loesungen/sovereign-ai/)** — GPU-Infrastruktur für KI-Workloads auf Hardware unter Ihrer Kontrolle. Passt zu: AI Platform. Kostenloser [Sovereign-AI-Architektur-Leitfaden](/de/ressourcen/sovereign-ai-architektur-leitfaden/).
- **[Private LLM](/de/loesungen/private-llm/)** — Open-Weight-Modelle, RAG und Fine-Tuning auf eigenen GPUs; Gewichte und Protokolle bleiben auf Ihrer Seite der Grenze. Passt zu: AI Platform.
- **[GPU-Cloud-Bursting](/de/loesungen/gpu-cloud-bursting/)** — Die Grundlast auf eigener Kapazität, Lastspitzen in Public- oder souveräne Clouds, alles unter einer Cluster API. Passt zu: AI Platform plus Public Cloud Platform.

### Auslöser aus Kosten und Konsolidierung

- **[Cloud-Repatriation](/de/loesungen/cloud-repatriation/)** — Verlagern Sie Workloads von AWS, Azure oder GCP auf souveräne oder On-Premises-Infrastruktur. Passt zu: Private Cloud Platform — oder Public Cloud Platform, wenn Sie die Kapazität weiterverkaufen. Kostenloses [TCO-Worksheet](/de/ressourcen/cloud-repatriation-tco-worksheet/).
- **[Cloud-Kostenoptimierung](/de/loesungen/cloud-kostenoptimierung/)** — Finden, wo Public-Cloud-Ausgaben versickern, und dann entscheiden, was in der Cloud behoben und was verlagert wird. Passt zu: Public Cloud Platform oder Private Cloud Platform.
- **[Hybrid-Cloud-Plattform](/de/loesungen/hybrid-cloud/)** — Eine Plattform, die On-Premises, Public Cloud und Edge überspannt. Passt zu: Private Cloud Platform oder Public Cloud Platform.

### Auslöser aus dem Engineering

- **[Managed Services verkaufen und abrechnen](/de/loesungen/managed-services-abrechnung/)** — für Hosting-Anbieter: ein Katalog aus Managed Datenbanken, Kubernetes, S3, VMs und GPU, minutengenaue Nutzungsabrechnung über Ænix Billing und WHMCS, Tenant-Suspendierung. Passt zu: Public Cloud Platform.
- **[Developer Self-Service](/de/loesungen/developer-self-service/)** — Golden Paths, die Umgebungen, Datenbanken und Services ohne Ticket bereitstellen. Passt zu: der Developer-Self-Service-Schicht der Private Cloud Platform. Kostenloses [Platform Engineering Maturity Assessment](/de/ressourcen/platform-engineering-maturity-assessment/).

## Nicht sicher, welche Lösung passt?

Nehmen Sie das **[Platform Readiness Assessment](/de/dienstleistungen/platform-readiness-assessment/)** — ein Festpreis-Projekt über 14 oder 28 Tage, das Ihren Ist-Zustand prüft, die passende Lösung und Plattform benennt und eine Migrations-Roadmap liefert. Oder [vereinbaren Sie ein Discovery-Gespräch](/de/kontakt/), und wir ordnen Ihr Anliegen direkt im Gespräch ein.
