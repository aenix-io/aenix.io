Users, Roles, and Groups

A user is a person's account in Ænix Platform linked to an email address. The same user can have access to multiple accounts but with different permissions in each.

The list of account users is located on the Users page.

Inviting a User

To add a user to the account:

  1. On the Users page, click Add in the lower right corner.
  2. Enter the user's email.
  3. Assign roles to the user.
  4. Click Invite.

If the user is already registered on the portal, they will be added to the account immediately. If not, they will receive a registration link by email. After registration, the user will automatically appear in the account.

Roles and Access

User access is determined by their roles. There are two levels of roles:

  • Account-level roles -- grant access to administrative functions and all projects in the account.
  • Project-level roles -- grant access to a specific project.

For more details about roles, see the Role System article.

The account administrator can edit any user's roles. To do this:

  1. On the Users page, click the desired user's entry.
  2. On the opened page, go to the Roles tab. Here you can add new roles and remove existing ones.

Access to a specific project is assigned on the project page under the Members tab. For more details, see the Projects article.

Removing a User from the Account

To remove a user:

  1. On the Users page, click the desired user's entry.
  2. Click the three-dot icon in the upper right corner → Delete.

After removal, the user will lose access to the account and all its projects.

Groups

If you need to manage permissions for multiple users at once, use groups. A group brings users together and allows you to assign shared roles and project access to them.

For more details, see the Group Management article.
